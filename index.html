إعدادات المزامنة الآمنة (Firebase)
لا تدخل بيانات مرضى فعلية إلا بعد موافقة جهة العمل والتأكد من سياسة استضافة البيانات وقواعد الوصول.

أدخل إعدادات مشروع Firebase المعتمد، ثم سجل الدخول بحسابك. عند عدم الاتصال تبقى البيانات محلية على هذا الجهاز. لا تُفعّل المزامنة قبل ضبط قواعد Firestore للمستخدم نفسه فقط.

قواعد Firestore المقترحة (تحتاج تخصيص UID)
rules_version = '2';
service cloud.firestore {
 match /databases/{database}/documents {
  match /users/{userId}/{document=**} {
   allow read, write: if request.auth != null
     && request.auth.uid == userId;
  }
 }
}
